# 递归工厂（Recursive Factory）

[English](README.md) | **中文**

Recursive Factory 是一个 Minecraft 1.21.1 的 NeoForge 模组，提供一个可反复使用的「口袋工厂」维度，并支持工厂套工厂。

安装 Sable 时，入口微缩预览也会显示房间里的物理结构及其移动、旋转。入口方块物理化或还原时保留原工厂和房间格子的绑定；房间内有已加载的物理结构时，房间会保持运行。

多人模式下，入口预览会显示房间里的其他玩家，包括皮肤、穿戴装备、位置与姿态；不显示旁观者和观看者自己。

无人房间里的生物不会因为玩家在另一间工厂中而被距离清除，命令方块召唤的生物同样适用；和平难度仍会清除敌对生物。

## 特性

- **递归工厂方块**：放下方块就会为它建一个专属房间。在旁边、或者正上方 / 正下方再放一个入口方块，房间会**并进同一个工厂**、跟着长大（而不是另起一个），所以想要多大的房间就铺多少个入口方块，也可以上下叠起来。
- **工厂屏障**：房间的墙和天花板。每一块屏障都是这个工厂链路的一个端点 —— 屋里任何一个漏斗对着屏障推，东西就会送到外面的入口方块；给屏障灌红石，入口方块就会在输出面发出去。**右键屏障 = 离开房间**。
- **什么都从墙里走**：物品、流体、机械动力的应力都从屏障墙与外面的入口方块进出。房间没有门，也就不需要把东西搬过门。
- **物品镜像传输**：通过 NeoForge 物品能力塞进去的东西（原版漏斗、以及支持范围内的机械动力物流），会从链路另一端的对面出来。
- **流体镜像传输**：同一条链路也带流体 —— 一边的储罐 / 泵能灌满另一边的储罐，或者喂给另一边的管道。机械动力管道自己不收东西、只会抽，所以它抽的时候会把入口方块缓冲里那一份交给它。
- **红石镜像**：给任意一端灌信号，另一端就亮，并且只在**信号离开的那一面**输出。和原版二极管一样，输入端不会被反过来供电，所以中继永远不会自锁。
- **蓝图大炮逐块打印工厂**：拿机械动力的**空白蓝图**右击入口，或用**蓝图与笔**框选入口，再把部署好的蓝图装入**蓝图大炮**。大炮先放置入口和空房间外壳，再使用相邻容器里的材料逐块打印内部。嵌套工厂也逐块建造；扩容工厂的多个入口共用一份内部打印任务，各自连接原来对应的房间区块。
- **一个「框」、六个面，每一面同时什么都能带**：入口方块是一个 1/16 厚、中间镂空的框，房间的微缩模型就挂在这个镂空里。面指的是**房间的哪一侧**，而不是东西往哪儿走：往北面接一个物品容器，东西就从房间北侧出来。**没有需要「打开」的东西** —— 物品、流体、红石与应力各走各的、互不干扰，所以同一个面可以同时接漏斗、管道和红石信号。不潜行的空手右击 = 进入工厂；**潜行右击不再切换任何东西**，扳手右击仍旧是旋转方块。
- **装了 Create: Electro Energetics 就有输电**：用 CEE 的**连接器**分别点击入口方块的外侧面与对应区块里的屏障墙，连接器会变成表面节点；两边接上线即可双向输电。每个入口方块的每一面，内外各装一个节点；扩容后相邻入口的同一面也可分别安装，独立连接各自的房间区块。没安装的面不生成节点；换位置前先用 Create 扳手拆掉原节点。升级前已有的表面节点和连线会保留。
- **扩容后仍然一块入口对应一个区块**：电力、物品、流体、红石和应力均按入口对应的 16×16 房间区块独立传输，同一方向的不同区块不合并。房间内部仍然连通；扩容时打开的内部边界不会转接到其他区块的外墙。
- **六个面、六条应力通道**：应力同样按面走。在外面驱动入口方块的哪一个**应力面**，屋里就只有**对应的那一面墙**转起来，六个面互不干扰。
- **一个入口方块 = 一个房间格子**：每个入口方块代表一个 **16×16×16** 的房间格子（底层屏障 + 雪块/白混凝土棋盘地板 + **14×14×13** 自由空间 + 顶层屏障），屏障壳就在区块边缘那一圈，所以单个格子的自由空间是 14×14。墙按房间**并集的轮廓**建，L 形 / 十字形在凹角处也封得住；两个格子合并时，中间那堵墙原来站的地板也会补上。 上下叠放的格子同样会并进同一个房间，中间的墙也会逐层打开。
- **方块面预览**：入口方块的面上按 1/16 缩放显示**它自己那一格**的微缩模型，正好嵌进框的镂空里、与框严丝合缝，**不会再比方块高**。采样是边到边的整格，所以 16 格正好铺满方块的一个面，相邻的两个入口方块预览也能接上。屏障壳不进预览 —— 于是透过框看到的就是房间本身。
- **进和出**：右键递归工厂方块进入；在房里右键任意一块屏障离开。

## 使用前要知道的事

- **旧存档不兼容。** 这一版房间只有原来一半高（16 格，原来 32 格），所以老工厂的房间会按新高度重建、上面那层壳会被拆掉；你原来建在新天花板以上的东西会留在原地、露在壳外。**建议为这一版开新世界。**
- **各面无需切换模式。** 物品、流体、红石和应力可以同时经过同一面；输电通过安装在表面的节点连接。
- **房间是个封闭盒子**：墙、地板、天花板都是工厂屏障，没有门也没有窗。**从里面右键任意一块屏障**就能出去，并且会回到你进来的地方。
- **接收物品 / 流体的容器必须紧贴墙面**：从墙里出来的东西落在**墙往里一格**的位置（就是它进来时的那一面），那里必须站着能收下它的东西 —— 离墙一格远的箱子什么也收不到。外面的方向同理：接收容器要**紧挨着入口方块**，放在东西出来的那一面旁边。
- **漏斗 / 管道泵只需要放在输入侧**：不用把房间四面都围上机器。你从哪一面喂，就只有那一面回答，一个漏斗或者一台泵就够了。如果对面没有任何东西收得下，物品/流体会留在端点自己的缓冲里，日志里会写一行说明；把接收容器补上它就流过去了。
- **机器必须贴墙才能进应力网**：贴在屏障上的轴、齿轮箱、机器才算在那面墙的网络上。地板是棋盘方块、不是屏障，所以摆在房间正中、四面不靠墙的机器什么都带不动。
- **墙的拐角那一列不算链路**：拐角方块两侧都是墙，后面没有房间、也就没有落点；单个格子的每一面因此只有**中间 14 列**能对接。贴着拐角搭的机器借不到链路 —— 往墙中间挪一格。
- **一个工厂只有一个颜色**：摆在已有工厂旁边的入口方块会**并进**那个工厂、沿用工厂本身的颜色，而不是你手上那个物品的颜色。
- **逐次扣材料，使用大炮的火药。** 内部方块、端子和线缆按打印步骤耗料、耗燃料，速度和每份火药的发射次数沿用机械动力配置。缺料时暂停，补齐后继续；等待不消耗燃料，也支持大炮的跳过缺料和创造板条箱选项。进度及工厂快照随大炮存档，修改原工厂不会改变已开始的任务。
- **嵌在里面的工厂会一起复制。** 房间里站着的入口方块通往它自己的工厂，蓝图会跟着走进去：那一座也一并读出，大炮会为它单独盖一间房，并把复制出来的入口方块接进新房间，所以复制品不会与原型共用机器。再往里嵌的工厂也一样跟到底，最多八层。扩容过（不止一格）的工厂**也能照样整座复制**。有两种情况会中止抓取、并在动作栏上说明，而不是只复制一半：嵌套超过八层；入口串成了环、绕回一座正在被读取的工厂。正在被读取蓝图的工厂会在那一瞬间停住，期间拒绝进入。
- **蓝图使用机械动力的工具与文件。** 文件写在机械动力的 `schematics/uploaded/<玩家>` 目录里。材料清单和进度包含内部任务。内部方块直接放入工厂维度，不显示跨维度飞行弹道；创造模式直接部署仍可一次放置完整工厂。
- **CEE 电缆也会一起复制。** 入口预览会显示房间里的电缆；工厂蓝图会保存内部电缆、表面节点、线缆附件和接触网，嵌套房间也包括在内。蓝图大炮需要对应材料；连向工厂外部的线不会复制。用蓝图与笔框选时，只要把线缆两端的方块都选入，入口无头端子、标签及其连线都会保存。蓝图大炮按数量消耗连接器、导线和附件材料，两端放置完成后补接线缆。旧版导出的蓝图需要重新框选，才能带上这些连接。
- **房间和入口按需加载。** 入口区块加载时，内部房间保持运行。玩家在工厂内时，该工厂所有已绑定入口的区块也会保持加载；入口位于另一座工厂内时，逐层向外维持加载，直到最外层入口。多名玩家共用加载请求，最后一名相关玩家离开或下线后释放临时请求，未被其它来源加载的区块随后正常卸载。
- **机械动力的包裹物流还没接**：原版漏斗、滑槽、漏斗（funnel）、物品能力，以及管道 / 泵都能用；包裹端口（package port）之类套在 contraption 上的物流还没接。

## 用法

1. 合成并放置一个递归工厂方块。在它旁边继续放可以把房间长大；房间形状跟着入口方块摆的形状走。
2. **没有需要打开的开关**：往某一面接什么（漏斗、管道、轴、红石信号，或 Create: Electro Energetics 的端子），它就通到房间里对应的那一面墙。
3. 右键方块，进入房间。
4. 在房间里建造。任意一面屏障墙都是物品、流体、红石与应力的进出通道。
5. 在房间里再放一个递归工厂方块，就有了嵌套工厂；每层退出都会回到包着它的那一层。
6. 右键工厂屏障离开房间，回到你进来的位置。
7. 想复制一个工厂，就拿一张**空白蓝图**（机械动力的，纸就能做）右击它的入口方块：模组会把房间（连同里面嵌套的工厂）读出来，并把一份指向所写文件的蓝图物品交给你。
8. 部署蓝图，在**蓝图大炮**旁边放好材料容器，给大炮装入蓝图和火药并开始打印。入口先出现，内部随后逐块建造；在大炮界面查看进度和缺少的材料。
9. 端点放好后，端子和线缆按步骤恢复。旧版的工厂打印机已删除；已有的镜像工厂物品仍可使用。

创造模式下，对准工厂入口按中键（拾取方块）即可取得链接到该维度和坐标的工厂方块，无需按 Ctrl。中键时不读取内部结构、不生成蓝图文件；物品提示会显示来源坐标。
每次放置时才读取该位置当前工厂的颜色、扩容布局、容器内容和嵌套工厂，并将相连的入口整座展开。中键后修改或扩容源工厂，下一次放置会包含这些变化。目标入口不存在或展开位置被占用时，动作栏会提示失败，什么都不放。链接按坐标查找：原位置换成另一座工厂后会复制新工厂；已放下的副本始终独立，不随源工厂后续变化。
旧版已取得的快照物品保持原行为；重新中键可取得坐标链接。

## 配置

`config/recursivefactory-common.toml`：

- `power.linkEnabled`（默认 `true`）：一个面的输电链路两端是否绑在一起。只在装了 Create: Electro Energetics 时有意义；关掉则每个端子各管各的。
- `power.linkResistance`（默认 `10`）：输电链路每一端的串联电阻，单位欧姆。
- `power.linkResponse`（默认 `0.5`）：链路每 tick 朝新设定值走多少。
- `power.linkMaxCurrent`（默认 `1000`）：链路一端最多能为自己推过多少电流，单位安培。
- `room.repairBrokenFloor`（默认 `false`）：是否把房间里缺失的棋盘地板补回来。
  关（默认）：一个房间格子的地板只在**这个格子第一次建成时**铺一次，之后你挖出来的洞就一直是个洞。
  开：每次查看房间（进房间、服务器启动）都会把**缺掉**的地板补回去；只补真正没了的那几格，
  你放在地板层上的别的东西一律不动。屏障壳与地板下的基岩**两种情况下都会补**。

## 开发

```powershell
.\gradlew.bat build --no-daemon --console=plain
```

项目面向 Minecraft 1.21.1、NeoForge 21.1.249 与 Create 6.0.10+。Create: Electro Energetics 是**可选依赖**：只有装了它，表面输电节点的接入逻辑才会启用；构建时只需要它的 API 在编译路径上（`compileOnly`）。入口方块的模型、贴图与投影渲染器设计参考了 MIT 许可的 Create: Pocket Factory 参考项目。
