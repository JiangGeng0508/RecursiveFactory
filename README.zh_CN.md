# 递归工厂（Recursive Factory）

[English](README.md) | **中文**

Recursive Factory 是一个 Minecraft 1.21.1 的 NeoForge 模组，提供一个可反复使用的「口袋工厂」维度，并支持工厂套工厂。

## 特性

- **递归工厂方块**：放下方块就会为它建一个专属房间。在旁边再放一个入口方块，房间会**并进同一个工厂**、跟着长大（而不是另起一个），所以想要多大的房间就铺多少个入口方块。
- **工厂屏障**：房间的墙和天花板。每一块屏障都是这个工厂链路的一个端点 —— 屋里任何一个漏斗对着屏障推，东西就会送到外面的入口方块；给屏障灌红石，入口方块就会在输出面发出去。前提是房间那一侧所属的**面**带的是你正在送的那种东西（见下面的面模式）。**右键屏障 = 离开房间**。
- **什么都从墙里走**：物品、流体、机械动力的应力都从屏障墙与外面的入口方块进出。房间没有门，也就不需要把东西搬过门。
- **物品镜像传输**：通过 NeoForge 物品能力塞进去的东西（原版漏斗、以及支持范围内的机械动力物流），会从链路另一端的对面出来。
- **流体镜像传输**：同一条链路也带流体 —— 一边的储罐 / 泵能灌满另一边的储罐，或者喂给另一边的管道。机械动力管道自己不收东西、只会抽，所以它抽的时候会把入口方块缓冲里那一份交给它。
- **红石镜像**：给任意一端灌信号，另一端就亮，并且只在**信号离开的那一面**输出。和原版二极管一样，输入端不会被反过来供电，所以中继永远不会自锁。
- **蓝图、打印机与工厂复制**：拿一份**镜像工厂蓝图**右击入口方块，它会把房间内容读成一份蓝图文件，并把指向这份文件的物品交给你。把这份蓝图装进**工厂打印机**，打印机就会用**紧贴着它的容器**里的材料，一格一格地在另一个房间里把同样的内容盖出来。最后产出的是一个**镜像工厂**物品：把它放下去，那个刚打好的房间上就会出现一个入口方块，于是这份复制品和别的工厂一样能用。之后每放一份镜像工厂物品，就再复制一份房间。
- **一个「框」、六个面**：入口方块是一个 1/16 厚、中间镂空的框，房间的微缩模型就挂在这个镂空里。它的六个面各带**一种**东西，六者互不干扰：

  | 面模式 | 带什么 |
  |---|---|
  | 透明 | 什么都不带 —— 这一面就是一扇窗 |
  | 红石 | 红石的输入输出 |
  | 物流 | 物品物流，原版与机械动力 |
  | 流体 | 流体 |
  | 应力 | 机械动力的应力 |

  面指的是**房间的哪一侧**，而不是东西往哪儿走：把北面切成流体，房间的北侧就是流体侧。**六个面默认全是透明**，所以新建的工厂六面什么都不通，要你自己把需要的那几面打开。**空手潜行右击**一个面、或者用**机械动力的扳手**右击它，就切到下一个模式（动作栏会报出来）；不潜行的空手右击则是进入工厂。那一面的框会按模式上色 —— 红石红、物流橙、流体蓝、应力绿，透明面保持工厂自身的颜色，所以一眼就能从框上看出六个面各是什么。
- **六个面、六条应力通道**：应力同样按面走。在外面驱动入口方块的哪一个**应力面**，屋里就只有**对应的那一面墙**转起来，六个面互不干扰。
- **一个入口方块 = 一个房间格子**：每个入口方块代表一个 **16×16×16** 的房间格子（底层屏障 + 雪块/白混凝土棋盘地板 + **14×14×13** 自由空间 + 顶层屏障），屏障壳就在区块边缘那一圈，所以单个格子的自由空间是 14×14。墙按房间**并集的轮廓**建，L 形 / 十字形在凹角处也封得住；两个格子合并时，中间那堵墙原来站的地板也会补上。
- **方块面预览**：入口方块的面上按 1/16 缩放显示**它自己那一格**的微缩模型，正好嵌进框的镂空里、与框严丝合缝，**不会再比方块高**。采样是边到边的整格，所以 16 格正好铺满方块的一个面，相邻的两个入口方块预览也能接上。屏障壳不进预览 —— 于是透过框看到的就是房间本身。
- **进和出**：右键递归工厂方块进入；在房里右键任意一块屏障离开。

## 使用前要知道的事

- **旧存档不兼容。** 这一版房间只有原来一半高（16 格，原来 32 格），所以老工厂的房间会按新高度重建、上面那层壳会被拆掉；你原来建在新天花板以上的东西会留在原地、露在壳外。**建议为这一版开新世界。**
- **一个面必须先打开，而且一次只带一种东西。** 红石、物品、流体、应力各要一个属于自己的面 —— 切成其中一种之后，这一面就不再带别的了。另外模式比这四种多一个：`透明`，也就是窗。
- **房间是个封闭盒子**：墙、地板、天花板都是工厂屏障，没有门也没有窗。**从里面右键任意一块屏障**就能出去，并且会回到你进来的地方。
- **接收物品 / 流体的容器必须紧贴墙面**：从墙里出来的东西落在**墙往里一格**的位置（就是它进来时的那一面），那里必须站着能收下它的东西 —— 离墙一格远的箱子什么也收不到。外面的方向同理：接收容器要**紧挨着入口方块**，放在东西出来的那一面旁边。
- **漏斗 / 管道泵只需要放在输入侧**：不用把房间四面都围上机器。你从哪一面喂，就只有那一面回答，一个漏斗或者一台泵就够了。如果对面没有任何东西收得下，物品/流体会留在端点自己的缓冲里，日志里会写一行说明；把接收容器补上它就流过去了。
- **机器必须贴墙才能进应力网**：贴在屏障上的轴、齿轮箱、机器才算在那面墙的网络上。地板是棋盘方块、不是屏障，所以摆在房间正中、四面不靠墙的机器什么都带不动。
- **墙的拐角那一列不算链路**：拐角方块两侧都是墙，后面没有房间、也就没有落点；单个格子的每一面因此只有**中间 14 列**能对接。贴着拐角搭的机器借不到链路 —— 往墙中间挪一格。
- **一个工厂只有一个颜色**：摆在已有工厂旁边的入口方块会**并进**那个工厂、沿用工厂本身的颜色，而不是你手上那个物品的颜色。
- **打印机为它盖的东西付账：材料 + 糖。** 每放下一个方块，它就从紧贴着的容器里取走一份对应的材料；一颗糖够它放 400 个方块。它**先要材料、后烧糖**，所以卡在等材料上的打印机不会白白耗掉燃料。缺料时它会停在这一格，你把料补上它自己接着打 —— 不用重头再来。
- **复制只支持一格房间。** 扩容过（不止一格）的工厂不能复制，蓝图物品会直接说明，而不是只复制一半。正在被读取蓝图的工厂会在那一瞬间停住，期间拒绝进入。
- **蓝图是文件，不是塞进物品的 NBT。** 它写在世界自己的 `recursivefactory/blueprints` 目录里，格式与机械动力的蓝图一致，所以装满机器的房间也不必塞进一个物品里。
- **机械动力的包裹物流还没接**：原版漏斗、滑槽、漏斗（funnel）、物品能力，以及管道 / 泵都能用；包裹端口（package port）之类套在 contraption 上的物流还没接。

## 用法

1. 合成并放置一个递归工厂方块。在它旁边继续放可以把房间长大；房间形状跟着入口方块摆的形状走。
2. 先把需要的面打开：空手潜行右击一个面，或者用机械动力的扳手右击它，依次循环 透明 → 红石 → 物流 → 流体 → 应力。动作栏会报出切到了哪一个。
3. 右键方块，进入房间。
4. 在房间里建造。你打开过的那些面对应的屏障墙，就是物品、流体、红石与应力的进出通道。
5. 在房间里再放一个递归工厂方块，就有了嵌套工厂；每层退出都会回到包着它的那一层。
6. 右键工厂屏障离开房间，回到你进来的位置。
7. 想复制一个工厂，就拿**镜像工厂蓝图**右击它的入口方块：模组会把房间读出来，并把一份指向所写文件的蓝图物品交给你。
8. 放下**工厂打印机**，在它周围摆上装有这个房间所需材料的容器（外加一些糖），再用蓝图右击它。它会把房间一格一格地打进一个属于它自己的房间里；空手右击它可以看到打到哪儿了、在等什么。打完后成品会进到它旁边的容器里，旁边没有容器就掉在地上。
9. 放下**镜像工厂**物品，刚打好的那个房间上就会出现入口方块。再放一份镜像工厂物品，它会**再复制一份**那个房间，而不是共用同一个。

## 配置

`config/recursivefactory-common.toml`：

- `printer.delay`（默认 `10`）：工厂打印机每放一个方块之间等待的 tick 数。一个房间是 16×16×13，按默认值打满大约要半小时。
- `printer.shotsPerSugar`（默认 `400`）：一颗糖能让打印机放多少个方块。
- `room.repairBrokenFloor`（默认 `false`）：是否把房间里缺失的棋盘地板补回来。
  关（默认）：一个房间格子的地板只在**这个格子第一次建成时**铺一次，之后你挖出来的洞就一直是个洞。
  开：每次查看房间（进房间、服务器启动）都会把**缺掉**的地板补回去；只补真正没了的那几格，
  你放在地板层上的别的东西一律不动。屏障壳与地板下的基岩**两种情况下都会补**。

## 开发

```powershell
.\gradlew.bat build --no-daemon --console=plain
```

项目面向 Minecraft 1.21.1、NeoForge 21.1.249 与 Create 6.0.10+。入口方块的模型、贴图与投影渲染器设计参考了 MIT 许可的 Create: Pocket Factory 参考项目。
